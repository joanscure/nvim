LSP y diagnósticos

lsp.lua · keymaps.lua

Sin distro (no LazyVim): todos los mapeos LSP son propios, definidos a mano en el on_attach de neovim/nvim-lspconfig (buffer-local) y en lua/config/keymaps.lua (globales). Formateo vía stevearc/conform.nvim (no hay none-ls/null-ls). Servers gestionados con mason.nvim + mason-lspconfig.nvim (sin mapeos propios, solo comandos: :Mason, :MasonInstall).

En este repo no se agregó ningún atajo de teclado: el README sugiere <leader>; para pick(), [; para goto_context_start() y ]; para select_next_context(), pero son solo un ejemplo de configuración — no vienen activados por defecto y este repo no los copió. La barra es puramente visual/clickeable con el mouse a menos que agregues esos mapeos vos mismo.
